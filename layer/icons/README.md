The in-game panel's icons: GNOME's Adwaita symbolic icons
(https://gitlab.gnome.org/GNOME/adwaita-icon-theme), the same ones Mace
Settings shows, licensed CC-BY-SA-3.0 OR LGPL-3.0-only. `dev/icons.sh` makes
these files from the installed theme: each is the icon's coverage, one byte a
pixel, at 16, 20, 24, 32, 40 and 48 pixels.
